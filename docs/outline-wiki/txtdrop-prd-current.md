# TXTDrop PRD

기준 문서: 기능명세.md / 작성자: Claude Code / 작성일: 2026-07-10 / 기준 버전: v0.7 / 대상: Windows 데스크톱 사용자

## 01. 제품 개요

TXTDrop은 클립보드의 텍스트 또는 이미지를 전역 단축키 한 번으로 파일로 저장하는 Windows용 유틸리티다. 저장 폴더, 파일명 접두사, 저장/낭독 단축키, Ollama 모델, 중복제거, 사운드, 언어, DB 백업/복원 옵션을 설정할 수 있다. v0.7부터 선택 또는 클립보드 텍스트를 SVIL TTS로 낭독하는 단축키와, 저장 기록의 중복 문서를 걸러 휴지통으로 옮기는 중복제거 기능을 제공한다. 낭독 시 TTS 서버가 꺼져 있으면 MCP `svil_tts_speak`과 동일한 경로로 자동 기동을 시도한다 (2026-07-10). 저장된 `.txt`는 연계 앱 TXTBrain이 수집한다.

## 02. 사용자

* 반복적으로 텍스트 스니펫을 저장하는 사용자
* 캡처 이미지나 클립보드 이미지를 빠르게 보관하려는 사용자
* 로컬 Ollama 모델로 의미 있는 파일명을 자동 생성하고 싶은 사용자
* 선택한 텍스트를 손을 떼지 않고 바로 음성으로 듣고 싶은 사용자 (저시력 접근성 포함)
* 트레이에 상주하는 가벼운 Windows 도구를 선호하는 사용자

## 03. 목표

* 클립보드 저장 과정을 전역 단축키 중심으로 최소화한다.
* 텍스트와 이미지를 각 저장 폴더에 안정적으로 저장한다.
* 텍스트 파일명은 AI 제목 또는 클립보드 첫 줄 기반 제목으로 알아보기 쉽게 만든다.
* 선택/클립보드 텍스트를 단축키 한 번으로 로컬 SVIL TTS로 낭독하며, 서버가 꺼져 있어도 가능하면 자동으로 켜서 이어간다.
* 중복 저장을 자동으로 걸러 저장 기록을 깔끔하게 유지하되, 되돌릴 수 있게 한다.
* 로그와 저장 이력을 앱 내부에서 확인할 수 있게 한다.
* 배포 가능한 PyInstaller/Inno Setup 빌드 흐름을 유지한다.

## 04. 주요 기능 범위

| 기능 | 범위 |
|------|------|
| 클립보드 텍스트 저장 | UTF-8 `.txt` 저장 |
| 클립보드 이미지 저장 | PNG 저장 |
| 저장 단축키 | 기본 `ctrl+shift+z`, 설정 창에서 변경, 등록 실패 시 폴백 |
| 낭독 단축키 (TTS) | 기본 `ctrl+shift+x`, 선택 텍스트(없으면 클립보드)를 SVIL TTS 프록시(:8765)로 낭독, 서버 미기동 시 웹 백엔드(:3000) 경유 자동 기동(최대 60초) |
| 중복제거 | 저장 직후 자동 검사(SHA-256 + difflib), 중복 기록을 `trash`로 이동, 중복제거 창에서 복구 |
| Ollama 제목 생성 | 서버 실행 시 모델 기반 제목 생성 |
| 파일명 폴백 | Ollama 미연결 시 클립보드 첫 줄 → 타임스탬프 순 |
| Ollama 자동 시작 | `ollama_autostart=true`일 때만 시작 시 `ollama serve` 무음 시도 |
| Ollama 수동 새로고침 | 트레이 메뉴에서 상태 확인/시작/설치 안내 |
| 설정 UI | 저장 폴더, 접두사, 저장/낭독 단축키, 모델, 자동 시작, 중복제거, 사운드, 언어, DB 백업/복원 |
| 로그/이력 UI | 최근 로그와 저장 기록 표시, 저장 파일 열기 |
| 중복제거 UI | 전체 스캔, 유사도 기준 조정, 휴지통 목록·복구 |
| TXTBrain 연계 | 저장 폴더의 `.txt`를 TXTBrain이 수집, 내용 해시로 중복 차단 |
| 빌드/배포 | PyInstaller onedir, Inno Setup 설치 파일 |

## 05. 비범위

* 클라우드 동기화
* 모바일 지원
* 다중 프로필 설정
* 서버 기반 사용자 인증
* 클립보드 내용의 자동 분류 저장
* 절전/복귀 전용 WNDPROC 핸들러 (안정성상 비활성화)
* 의미 유사도(임베딩) 기반 중복 판정 (완전 동일/문자 유사도만 대상)

## 06. 성공 기준

* 앱 시작 시 저장/낭독 단축키가 각각 등록된다 (실패 시 기본값 재시도).
* 텍스트 클립보드는 지정 폴더에 `.txt`로 저장된다.
* 이미지 클립보드는 지정 폴더에 `.png`로 저장된다.
* 저장 성공 시 히스토리와 로그가 기록된다.
* 낭독 단축키로 선택/클립보드 텍스트가 SVIL TTS로 재생된다. TTS 서버가 꺼져 있으면 자동 기동을 시도하고, 그래도 실패하면 오류 안내를 표시한다.
* 저장 직후 중복이면 해당 기록이 `trash`로 이동하고, 중복제거 창에서 복구할 수 있다.
* `ollama_autostart=false`일 때 시작 시 Ollama 자동 실행을 시도하지 않는다.
* 트레이 "Ollama 새로고침"으로 실행 중 Ollama를 인식할 수 있다.
* `build.bat` 또는 동등한 PyInstaller 명령으로 `dist\TXTDrop\TXTDrop.exe`가 생성된다.
* 첫 실행 시 폴더 선택 대화상자가 정상 표시된다.

## 07. 리스크

* `keyboard` 전역 훅은 Windows 권한과 보안 소프트웨어 상태에 영향을 받을 수 있다.
* Tkinter UI는 반드시 공유 루트와 메인 스레드 이벤트 루프 규칙을 지켜야 한다.
* PyInstaller frozen 런타임에서 ctypes WNDPROC 패치는 크래시 위험이 있다.
* Ollama 서버 상태와 모델 목록은 로컬 설치 상태에 따라 달라진다.
* SVIL TTS 낭독의 자동 기동은 로컬 웹 백엔드(:3000)가 살아있어야 동작한다. 웹 백엔드까지 꺼져 있거나 기동이 60초를 넘기면 낭독이 실패한다.
* 중복제거 자동 검사는 백그라운드로 동작하므로, 오판 시 기록이 `trash`로 이동할 수 있다 (복구 가능).
* `keyboard` 논데몬 스레드로 인해 `sys.exit()`만으로는 프로세스가 종료되지 않을 수 있다.
